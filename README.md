# 苔·迹（MossMark）

一款专为中学生打造的学习成长记录软件。待办、日记、试卷、成绩、目标——把学习生活的方方面面装进一个 App。**软件完全单机运行，无需注册登录，数据全部保存在本地，隐私性极高。**

> 白日不到处，青春恰自来。让每一天的努力，都留下苔花般的痕迹。

---

## 功能特点

| 功能 | 说明 |
| --- | --- |
|  待办清单 | 按日期管理学习任务，逾期任务醒目提醒，左右滑动即可删除，完成度一目了然 |
|  心情日记 | 随手记录每天的所思所想，自动按日期归档，随时回顾来时路 |
|  试卷收藏 | 拍照录入试卷，像文件夹一样分类归档，复习时一键翻阅，支持导出保存 |
|  成绩记录 | 录入历次考试成绩，自动生成趋势图表，进步退步一目了然 |
|  目标打卡 | 时间线式进度追踪，每一个坚持的日子都会被点亮 |
|  深色模式 | 自动适配深色/浅色主题，夜间学习不伤眼 |
|  个性字体 | 内置多款可爱手写字体，打造专属风格 |
|  隐私安全 | 无需登录、无需联网，所有数据仅保存在你的手机上 |

## 下载安装

1. 打开本仓库右侧的 **[Releases](../../releases)** 页面（或点击右侧栏 Releases）。
2. 在版本列表中找到最新版本，点击 **Assets** 下的 **`MossMark-vX.X.X.apk`** 下载。
3. 手机上打开下载好的 APK，如果提示「允许安装未知来源应用」，请选择**允许**。
4. 安装完成，打开即可使用，无需注册任何账号。

> ⚠️ 仅支持 Android 系统；本软件不开联网权限，请放心使用。

## 使用教程

### 待办清单
- 点击左侧小竖条 **+ 添加待办**，输入任务内容，点击右侧小竖条可以查看日期进度。
- 点击任务前的**圆圈**即可打勾完成；向**左滑动**任务卡片可删除。
- 逾期未完成的任务会以红色光晕醒目提示。

### 心情日记
- 今日页面的绿色大卡片滑动即可切换到随笔，输入今天的想法，自动保存。
- 我的页面最下方可以查看历史随笔。

### 试卷收藏
- 在记录页再次点击记录即可切换收录页面，点击**新建文件夹**，为科目或学期创建分类（如「高一期中」）。
- 长按文件夹最外层卡片可**拍照录入试卷**，支持一次录入多张。
- 点击文件夹可以展开查看里面的试卷卡片。
- 点击第一张卡片可进入杂志式浏览页，支持全屏预览、左右翻页和整体导出保存。

### 成绩记录
- 点击记录页面的**录入成绩**，选择考试类型（月考/期中/期末），录入各科分数。
- 软件自动计算总分并绘制成绩趋势图。
- 下次考试录入后，自动对比上次成绩，进步/退步一目了然。

### 目标打卡
- 点击计划页面右下角 **+** 新建目标/计划，设置名称、期限和提醒。
- 每天开始执行计划从专注页面载入计划卡片，每次完成点击打卡，坚持记录看得见。
